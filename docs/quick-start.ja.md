# Clientre 5 クイックスタート

> 本体への書き込み方法は [README](../README.md#書き込み) を参照してください。

## 1. 初回起動

1. TF カードを挿し、電源を入れます。
2. 言語選択画面で **日本語** を選びます（後から **設定 → システム → 言語** で変更可。変更時は再起動します）。

## 2. WiFi

**WiFi** タイルから、スキャン結果をタップして接続、または手動で SSID とパスワードを入力します。
オープンネットワークはパスワード空欄で接続できます。接続後は NTP で時刻同期し、RTC に書き戻します。

## 3. SSH ターミナル

1. **SSH ターミナル → +** でサーバーを登録（名前、ホスト、ポート、ユーザー名、パスワード、または SD 上の秘密鍵）。
2. カードをタップして接続。初回はホスト鍵の指紋を確認して信頼します（NVS に保存）。
3. 画面端のホットゾーン: **上端** = ステータスバー、**左端** = コントロールバー（ESC/TAB/CTRL/ALT/矢印/HOME/END/PgUp/PgDn/F キー/^C/^Z/^D）、**右端** = ソフトキーボード。
4. 履歴は画面を上下にドラッグ、または Shift+PgUp/PgDn でスクロールします。

## 4. 日本語入力

| 操作 | 内容 |
|---|---|
| Ctrl+Space / ソフトキーの「A/あ」 | 入力ソース切替（英語 → 日本語 → 英語） |
| ローマ字入力 | 自動でひらがなに変換（`kyou`→きょう、`nn`→ん、`kk`→っk） |
| Space | 変換開始・次候補、`1`〜`9` で候補選択、PgUp/PgDn で候補ページ送り |
| Enter | 確定（確定文字列は UTF-8 で送信） |
| Esc | 変換の取消／入力の破棄 |
| F6 / F7 / F8 | ひらがな／カタカナ／半角カタカナで確定 |
| `,` `.` `[` `]` `!` `?` | 日本語モードでは 、。「」！？ に変換 |
| 設定 → 入力 → 日本語 | ひらがな／カタカナのデフォルトを切替 |

辞書は SKK-JISYO.M を内蔵しています。より大きい辞書を使う場合は TF カードの `/skk/SKK-JISYO.L` に置き、
**設定 → 入力 → SD: /skk/SKK-JISYO.L** をオンにします（PSRAM に読み込みます）。
UI 言語が中国語の場合は、切替順に拼音入力（LVGL 付属の小辞書）が加わります。

## 5. 物理キーボード

Tab5 キーボード（I2C 0x6D）または USB キーボードを検出すると、ソフトキーボードは自動的に表示されなくなります。
Ctrl+文字、Alt+文字、矢印、Home/End、F1〜F12 はそのまま端末に送られます。キーボード LED の色と明るさは設定から変更できます。

キーボードだけで画面全体を操作できます。選択中の項目は枠で表示され、画面外の項目へ移動すると自動でスクロールします。

| キー | 操作 |
| --- | --- |
| Tab / Shift+Tab | 次／前の項目へ移動 |
| Enter / Space | ボタンを実行、スイッチを切り替え |
| Esc | 戻る、ダイアログをキャンセル |
| 矢印 | 項目を移動。入力欄ではカーソル移動、スライダーでは値を変更 |
| Shift+矢印 | スライダーを10刻みで変更 |
| PageUp / PageDown | リストをスクロール |
| Ctrl+Enter（Shift/Fキー不要） | 選択項目の長押しメニュー |
| Ctrl+Tab（SSH中） | SSH入力と画面操作を切り替え。画面操作中のEscでもSSH入力へ戻る |
| Shift+PageUp / Shift+PageDown（SSH入力中） | 端末の履歴をスクロール |

入力欄では通常どおり文字入力・IME変換ができます。確定ボタンへはTabで移動します。SSH入力中のTabやEscは接続先に送られますが、確認ダイアログが開いている間はダイアログの操作になります。

画像は表示領域をTabで選択して矢印でスクロールできます。従来のスクリーンセーバーの各要素の配置は、設定画面の「X, Y」から数値で変更できます。スクリーンセーバー表示中は任意のキーで復帰します。


## 6. ファイル管理・画像・テキスト・音楽・カメラ

- **ファイル管理**: TF カードと USB メモリを閲覧。長押しで名前変更・コピー・切り取り・削除・選択、右上の + から新規作成・貼り付け・全選択。
- **画像**: JPEG（ハードウェアデコード、大きい画像はソフトウェア縮小）、PNG/BMP/GIF。EXIF 情報表示、左右スワイプで前後の画像、拡大縮小と回転。
- **テキスト**: UTF-8 / UTF-16 のテキストを等幅フォントで表示。フォントは JIS X 0208・JIS X 0213 第3/4水準・
  半角カタカナ・互換漢字・単位記号（㎡ ㌔ など）を収録しています。
- **音楽**: MP3/FLAC/WAV。`/Music` 以下（無ければカード全体）を検索。長押しでお気に入り登録、アルバムアート表示、他画面でもバックグラウンド再生バーが表示されます。
- **カメラ**: プレビュー表示。撮影した写真は `/DCIM/Clientre5` に JPEG で保存されます。

## 7. Web ファイルマネージャ

**Web ファイル** で開始すると `http://<IPv4>/` からブラウザでアップロード・ダウンロード・編集ができます（QR コード表示）。
WiFi 経由で大きなファイルを多数アップロードすると不安定になることがあります。

## 7.5 外観・操作・セキュリティ

- **フォントはテーマと言語に連動**します。Orange EL / Retro CRT / Pixel の英語・日本語は
  MaruMinyaを整数倍のピクセル表示にします。中国語は画面内で書体が混ざらないよう、英数字も含めて
  Noto CJKに統一します。Dark / Light / Nord / Solarized / Gruvbox / Classicでは通常の滑らかな
  MontserratまたはNoto CJKへ切り替わり、SSH端末も滑らかな等幅CJK書体になります。
- **外観**（設定 → 画面 → 外観）: 既定は **Orange EL**（黒地・アンバー文字・角丸なし・発光・走査線）。
  ほかに Retro CRT（グリーン蛍光体）、Pixel、Dark、Light、Nord、Solarized Dark、Gruvbox、Classic。
  8 色の個別指定、角の丸み、余白の密度、発光、走査線、タイル配色、
  ターミナルの前景/背景/カーソル色、ANSI 16 色、カーソル形状、点滅、行の高さを変更できます。
- **ステータスバー**（設定 → ステータスバー）: WiFi / Tailscale アイコン、IP、バッテリー、時刻、日付などを
  個別にオン/オフ。接続中はアイコンが点滅し、未接続時は灰色で表示されます。
- **ジェスチャー**: どの画面でも**右スワイプで戻る**。ホームのタイル**長押し**でショートカット
  （SSH=サーバ追加、ファイル=USB メモリ、音楽=再生/一時停止、WiFi=切断、Tailscale=オン/オフ、設定=外観）。
  音楽と画像は左右スワイプで曲/画像送り。ターミナルは長押しでメニュー。
- **セキュリティ**（設定 → セキュリティ）: SSH サーバ一覧を TF カードに暗号化保存できます。
  端末鍵は本体に残るため、カードだけでも本体だけでも復号できません。カードが無い場合は一覧が空で起動し、
  挿し直せば復帰します。

## 8. USB

- **USB ディスクモード**: TF カードを PC に USB ストレージとして公開します。**USB-C を PC に接続**してください。
  有効中は本体側から TF カードにアクセスできず、また USB-C が USB シリアルから切り替わるため
  **シリアルコンソールと書き込みができません**（画面の「停止」を押すか電源を入れ直すと戻ります）。
  USB-A のホスト機能は別のコントローラなので、USB キーボードなどはそのまま使えます。
- **USB メモリ**: USB-A に挿したメモリを `/usb` にマウントし、ファイル管理から操作できます。FAT32 でのフォーマットも可能です。

## 9. ファームウェア更新

**ファームウェア** 画面で更新を確認 → SD にダウンロード → インストール。インストールするとアップデーター（factory 領域）に再起動して書き込みます。
Launcher から起動した場合（アップデーターが無い場合）は Launcher で更新してください。

## 10. Tailscale で遠隔 SSH

ホームの **Tailscale** タイルから tailnet に参加できます(非公式クライアント MicroLink を内蔵)。

1. `login.tailscale.com/admin/settings/keys` で auth key を作成します(reusable と pre-authorized を有効にすると楽です)。
2. 画面で入力するか、TF カードの `/tailscale/authkey.txt` に保存して「SD から鍵を読み込む」を押します。
3. 「Tailnet に参加」をオンにします。接続後はピア一覧が表示され、タップすると SSH サーバーとして登録できます。
   サーバーのホスト名には tailnet 上の名前(`nas` や `nas.tailxxxx.ts.net`)をそのまま使えます。
4. Headscale を使う場合は「コントロールサーバー」に URL を設定します。

ノード鍵は本体に保存されるため、auth key は初回だけ必要です。

既定では全ピアを DERP 中継で通します(直接経路は厳しい NAT 下で片方向しか通らずデータが止まることがあるため)。遅延は 50〜150ms 程度増えます。初回接続は DERP 地域の切替とハンドシェイク待ちで 5〜30 秒かかります。「直接接続(実験的)」をオンにすると従来どおり直接 UDP を試します。

相手が Tailscale SSH(`SSH-2.0-Tailscale`)の場合、認証は tailnet の身元で行われるのでパスワードは空にします。既定 ACL の `"action": "check"` はブラウザ確認が必要で Tab5 では通らないため、Tab5 に `tag:tab5`、相手に `tag:server` を付け、`"action": "accept", "src": ["tag:tab5"], "dst": ["tag:server"]` のルールを追加してください(送信元がタグのとき `dst` にユーザーや `autogroup:member` は使えません)。
